# V2-P00 — Baseline Freeze & Scientific Audit

Date: 2026-09-14
Status: complete. No V2-P01 work started.

## Scope

Make `v0.1.0-rc1` a read-only scientific baseline and say what it is worth. Freeze the code,
configuration, data cards, artifacts and reports by SHA-256 into a machine-readable manifest; audit
the plan's two milestones and twelve final success criteria against the release's own artifacts; draw
the boundary between an engineering release candidate, a synthetic mechanism laboratory and a
regional historical model; and agree where V2's phases will be written down. The scope document is
`docs/exec-plans/V2-P00.md`; this report is what came out.

### Acceptance criteria

```text
v0.1.0-rc1 unmoved, its artifacts unchanged, working tree clean
a machine-readable baseline manifest that rebuilds identically and detects any file drift
each artifact recorded with its own generation commit, never with the current HEAD
M1, M2 and the twelve success criteria marked met/partial/unmet/not-testable with resolvable evidence
every V1 mechanism card listed with dataset, climate mode, sample size, policy arms, extrapolation
pytest, ruff, ruff format --check, mypy and doctor run, with their real output reported
an independent read-only review of sample sizes, synthetic inputs, thresholds, runtime refusal and
artifact lineage
```

### Non-goals

No V2-P01 work; no mechanism, parameter, rule, tick-order or historical-data change; no V1 artifact
re-run or rewrite; no re-tag; no V1 document corrected in place; no new dependency; no LLM call.

## Contract decisions

1. **Frozen content comes from git, not from the working tree.** Every frozen file is read as the
   blob it is in the baseline commit, so the manifest describes the release rather than whatever the
   tree held when the phase ran. The build refuses to freeze a tree in which a frozen file differs
   from the commit, so a manifest cannot be taken over uncommitted work — a test builds a repository,
   edits a file and asserts the refusal.
2. **An artifact's generation commit is the one the artifact recorded.** Each of the ten artifact
   directories carries `generation_commit`, `generation_commit_source` (`artifact-manifest` or
   `unrecorded`), `git_dirty_at_generation` and whether that commit is an ancestor of the freeze.
   HEAD is never substituted: nine of the ten recorded a commit, and **all nine recorded a commit
   older than the release**, seven of them from a dirty tree. `outputs/analysis` recorded
   nothing at all — nine Parquet files with no manifest — and the freeze says `unrecorded` rather
   than borrowing an identity.
3. **Additions and tracked edits are reported; the release is not allowed to move.** A frozen tracked
   file that changed is listed with a count and does not fail the check, because a working tree is
   what V2 evolves. What fails: a frozen file that vanished, any change *inside* a V1 artifact
   directory, a new file inside one, and a manifest that no longer hashes to the commit it names.
   That is the distinction the phase is built on, and each case is a test.
4. **The judgement is declared; the numbers are read.** The statuses and verdicts live in
   `release/audit.py`, because a status is an argument. Every countable fact — which batches a card
   cites, their row counts, replicates, seeds, arm labels, design kind, recorded generation commit —
   is read from `docs/v2/baseline-v1.json` and `docs/mechanisms/cards.yaml`. A card's sample size in
   the matrix cannot drift from its artifact: the integration test re-reads each Parquet file's row
   count and compares.
5. **Every citation resolves or the command fails.** `verify_audit` resolves each path (globs
   included) and each source-registry id against `sources/registry/*.yaml`; `audit` exits non-zero
   with the unresolved paths named. This caught two real citation bugs during the phase: source ids
   being treated as file paths, and the matrix citing itself before it had been written.
6. **The census is measured, not remembered.** The sandbox scale in every card's row is computed by
   building the declared fixture (`build_integrated_economy`): 8 nodes, 5 county nodes, 3 external
   nodes, 25 weighted household cohorts, 21,000 households, 5 elite houses, 7 merchant houses, 5
   county governments, 5 garrison units, 0 armed bands at start. This is what exposed the finding
   below.

## What the freeze and the audit found

1. **The staged provenance of V1's artifacts is thinner than V1's prose implies.** All nine
   artifact families that recorded a commit recorded one *older* than the release, seven of them with
   `git_dirty: true` (the P12 batch recorded no dirty flag at all). `outputs/analysis` has no manifest at all. `parameter_hash` is `null` in the
   run manifest. Criterion 12 is therefore marked **partial**, and this phase's own manifest is the
   artifact that makes the gap auditable rather than invisible.
2. **Five V1 sentences misstate the sandbox they rest on.** `docs/mechanisms/cards.yaml` (M001,
   M002, M003), `docs/mechanisms/index.md` and `outputs/reports/mechanism-synthesis.md` say the
   evidence rests on "three counties, thirty-two cohorts". The declared toy fixture is **five**
   counties and **twenty-five** cohorts; thirty-two is the P09 *particle* count. V1 is frozen, so the
   sentence is not edited: it is recorded in the audit's section 5, with the measured census and the
   code that produces it. V2-P02 should put a space census in the run manifest so it can never again
   be written from memory.
3. **Milestone M1 is `partial`, not met.** The LLM-free half holds (the runtime arm was never
   called), and the sensitivity + ablation + counterfactual triple test exists for crisis gating. But
   the calibration is a 32-particle pipeline rather than a posterior, two of thirteen parameters are
   unpinned across sampler seeds, and three of the eight reserved patterns are contradicted with the
   model's own falsifier — a contradiction that traces to the stationary synthetic climate, which
   makes those claims untestable in this model rather than wrong in it.
4. **Milestone M2 is `partial`, and cannot be more while the gate is closed.** The arm the milestone
   names by model never ran: P11 refused `USTC_LLM_MODEL` and P12 recorded the refusal. What holds is
   narrower — consolidation in 5 of 6 replicates under each of the three declared offline policies,
   extraction inversion under exactly one of them, a tipping region that moves with the policy.
5. **Five criteria `met`, six `partial`, one `unmet`.** Met: rule provenance (1), calibration/hold-out
   separation (3), real interventions (5), historical counterexamples (9), falsifiable predictions
   (10). Unmet: multi-scale patterns explained together (2) — two target patterns are systematically
   unsatisfied and three reserved patterns fail. The partial six are where V2's work is: sensitivity
   (4), removable mechanisms (6), parameter regions (7), tipping surface (8), LLM transparency (11),
   replayability (12).
6. **Exactly one artifact family in the release can be replayed end to end.** The demo scenario's
   digest is reproduced by a regression test; everything else is reproducible in principle from a
   commit and a seed, with the qualifications in (1).

## Open items for V2-P01 and later

- **V2-P01 must not inherit the citation discipline as a convention.** The freeze proves 13 of 25
  sources were never opened and that the registry holds no archival material; the rights spine is
  where that changes, and `docs/v2/v1-acceptance-matrix.md` criterion 1 is the evidence.
- **A space census belongs in the run manifest.** This phase had to build the sandbox to measure it,
  which is why a card could carry the wrong scale for a whole release. V2-P02 should record nodes,
  cohorts, elites, merchants and governments per run.
- **`parameter_hash` is still `null`** in `RunManifest`, carried open since P09; criterion 12 cannot
  move to `met` until it is wired.
- **`outputs/analysis` has no manifest**, so nine V1 analysis tables have no generation commit. A V2
  phase that regenerates analysis outputs should write one.
- **Seven artifact families were generated from a dirty tree.** Their recorded commit does not fully
  determine their code; V2 batches should refuse to run dirty or record the diff hash.
- **The audit's statuses are this phase's judgement, and V2-P09 should re-mark them all** from V2
  artifacts rather than from these rows.
