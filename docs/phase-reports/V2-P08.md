# V2-P08 — Runtime Policy Completion

Status: **refused — the manual gate is closed.** M2 stays incomplete. No V2-P09 work started.

## The gate

The phase's first instruction is a human gate: the operator must have confirmed the exact DeepSeek
V4.1 model id against the USTC account's `/v1/models` and enabled it in the uncommitted `.env`. The
gate is **not open**:

| check | value |
| --- | --- |
| `USTC_LLM_ENABLED` in `.env` | **`0`** — the runtime layer is off |
| `USTC_LLM_MODEL` in `.env` | **`deepseek-flash`** — not the confirmed id, and the prompt forbids switching to flash or pro |
| `USTC_LLM_API_KEY` in `.env` | present; **not read, printed, logged or committed** |
| `.env` tracked by git | no (`git ls-files .env` returns nothing; `git check-ignore` confirms) |

Two independent refusals follow, and both were exercised rather than assumed:

```text
confirmed_model_id("deepseek-flash")   -> ModelNotConfirmedError
confirmed_model_id("deepseek-v4.1-pro")-> ModelNotConfirmedError
confirmed_model_id("deepseek-v4.1")    -> ModelNotConfirmedError   (a near miss is not a confirmation)
confirmed_model_id("ustc-deepseek-v4.1")-> accepted
load_settings()                        -> ModelNotConfirmedError, before the credential is touched
```

`load_settings` validates the model gate **before** the enable switch and **before** any credential
source is called: the module's tests hand it a credential source that fails the test if it is
touched, and the refusal above is proof of the order in practice.

## What was therefore not done

Per the phase's own instruction — record `refused`, keep M2 incomplete, write this report, stop — none
of the gate-open work was attempted:

- **no observation corpus** was built or audited for anonymisation;
- **no live suite** ran, and no recording smoke: nothing confirmed the model-reported id, the schema
  refusal, the timeout, 429 handling or the cost of a call;
- **no fixtures** were sanitised and hashed, and no runtime arm ran on `historical-core-v1`;
- **no policy-robustness comparison** including the runtime arm was produced;
- **M2 is not upgraded**, and nothing in this phase claims a model's answer.

The live tests are deselected by the project's own configuration (`addopts = "-m 'not live_ustc'"`,
`live_ustc` opt-in only), so the default suite cannot reach the endpoint by accident.

## What the gate needs to open

1. The operator confirms, from the USTC account's own `/v1/models`, the exact id of DeepSeek V4.1.
2. `USTC_LLM_MODEL` in the uncommitted `.env` is set to **that** id — not to `deepseek-flash`, and not
   to any variant the operator has not seen listed.
3. `USTC_LLM_ENABLED=1` is set in the same file.
4. The phase is then re-run: the corpus, the live smoke, the fixtures, the runtime arm and the
   comparison follow in that order, and M2 is upgraded only if the arm has enough replicates for an
   interval — otherwise it is reported as a pilot.

None of those four steps may be replaced by guessing an id, by switching to a flash or pro model, or
by a scripted answer standing in for a model's. That is what the refusal means.

## Independent review

An adversarial reviewer tried to falsify the refusal from the tree and by exercising every reachable
route. Verdict: **approve**, with two minors carried.

- **It could not reach the network or the credential.** With a credential source that fails the test
  if it is touched, `load_settings()` refused with `ModelNotConfirmedError` under the real
  environment and under both simulated `.env` states — disabled and enabled — so enabling the switch
  does not admit an unconfirmed model. The CLI's replay route refused an empty fixture store before
  writing anything, and a `p12` run over `("rule", "ustc")` recorded `ustc: refused, decisions: 0`
  with the verdicts computed from the one arm that ran.
- **No other egress**: the only transport construction in `src/` is the one in `ustc_v41.py` with
  `max_retries=0`, no test outside the live ones names the endpoint, and nothing loads `.env` into
  the process environment.
- **Secret rule verified without printing the value**: the key appears in no tracked file and in no
  file outside `.env`; `.env` is untracked, gitignored and has never been committed; `.env.example`
  carries an empty key and `USTC_LLM_ENABLED=0`; and naming the live test file directly still
  deselects it.
- **Fail-closed confirmed**: a fixture miss raises rather than answering (even in the allow-missing
  mode the CLI never selects), a replay cannot invent an exchange and refuses an endpoint-reported id
  that differs from the confirmed one, and a refused arm is excluded from every verdict — it can only
  lower a robustness claim, never inflate one.
- **The report is honest**: nothing under `outputs/` could only have come from a model call, no
  document presents the runtime arm as having run, and M2 is declared incomplete.

Two minors the reviewer raised are carried rather than fixed here, because both are about the
*comparison* that has not run: the robustness threshold relaxes to `min(ROBUST_ARMS, arms_ran)` when
arms are missing (declared, printed, but worth a caveat line in the P12 report), and the committed P12
report embeds the earlier run's refusal wording, from a time when no model was configured at all.
