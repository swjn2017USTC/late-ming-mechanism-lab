## Decisions

1. **Package name.** The scaffold used `src/late_ming_mechanism_lab` while the plan specifies
   package `late_ming_lab` and CLI `late-ming-lab` (P01 prompt). The scaffold directory was
   removed and `[tool.uv.build-backend] module-name = "late_ming_lab"` was set so the project
   name (`late-ming-mechanism-lab`) still matches the repository.
2. **Routing home.** Per-agent models live in `.omp/config.yml` `task.agentModelOverrides`
   (documented as authoritative over agent frontmatter), so routing is visible in one file and
   agent definitions do not duplicate it.
3. **Schema fidelity.** The plan's suggested `advisor.subagents` key does not exist in the
   current schema and was not written; `advisor.enabled: false` is the real switch. `cycleOrder`
   was left at its default (`["smol","default","slow"]`) rather than restated. The `vision` role
   was left unset.
4. **Subagent ceiling.** `task.maxConcurrency: 2` encodes the "complex tasks ≤ 2 subagents"
   discipline; the phase-gate allowance of 3 is a deliberate, documented exception and was not
   encoded as a permanent setting.
5. **CLI scope.** Only `--version` exists in P00. `smoke-run` and the simulation commands belong
   to P01; adding them now would be unused surface.
6. **Runtime LLM.** No client, no credential read, no live call, no fixture. `USTC_LLM_ENABLED=0`
   in `.env.example`; `.env` remains gitignored and untracked. Enforcement is a test, not only a
   document.
7. **Tests.** Two tests only: the CLI smoke test and the runtime-LLM/credential invariant. No
   tests were added for scaffolding that does not yet exist.
8. **`live_ustc` marker** is declared in `pyproject.toml` now so `--strict-markers` stays valid
   when P11 adds live tests; the default suite remains offline.
