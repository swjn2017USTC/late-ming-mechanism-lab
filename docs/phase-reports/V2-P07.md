# V2-P07 — Sensitivity & Counterfactual V2

Status: complete, and **both ladders non-converged**. Run against `docs/exec-plans/V2-P07.md`.
No V2-P08 work started, and the reserved windows are still shut.

## What was built

`src/late_ming_lab/experiments/sensitivity_v2.py` turns V1's single screens into ladders with
declared gates, and writes every level, bound and adaptive choice into one manifest. The screen runs
over **every declared prior** — the support the frozen posterior was drawn from — and the Sobol stage
runs over the screen's strongest parameters with the rest held at their cards' central values, named
in the artifact.

| element | declaration |
| --- | --- |
| Morris ladder | 20 → 40 trajectories; top-4 set must survive a 200-resample trajectory bootstrap in ≥ 0.80 of resamples |
| Sobol ladder | N = 64 → 128 → 256, `calc_second_order=False`; stop when the largest S1 move is ≤ 0.20 of the previous level's value |
| PAWN | beside Sobol, for a skewed or non-monotone output, labelled `distributional, not causal` |
| arms | paired CRN, 16 → 32 → 64; stop on interval width ≤ 0.25 and a minimum substantive effect of 0.02 |
| tipping | 5 × 5 points × 8 seeds, then adaptive boundary points on new seeds, re-verified on reserved seeds |
| near-constant output | no quantitative reading: reported undefined with the reason |

## What the pilot found: non-convergence, twice

The pilot ran on the 48-tick toy window; the screen swept all thirteen declared priors.

| ladder | level | runs | verdict | the number behind it |
| --- | --- | --- | --- | --- |
| Morris | 20 trajectories | 280 | **unstable** | the bootstrap reproduced the top-4 set in **0.00** of 200 resamples |
| Morris | 40 trajectories | 560 | **unstable** | … in **0.01** of resamples |
| Sobol | N = 64 | 512 | not comparable | the first level has nothing to compare with |
| Sobol | N = 128 | 1,024 | **unstable** | the largest S1 move against N = 64 was **12.07×** the previous value |
| PAWN | N = 64 | 512 | reported | six parameters, `minimum`/`mean`/`median`/`maximum`, labelled distributional |

The Morris ranking is *nearly* stable — the leading four parameters are the same at both levels
(`subsistence_grain_per_adult_month_shi`, `assessed_value_tael_per_mu`, `reference_price_tael_per_shi`,
`yield_loss_scale`, in a slightly different order) — but the declared test is exact set agreement over
a 13-parameter design, and that is what it measured. The Sobol stage's S1 estimates move by an order
of magnitude between N = 64 and N = 128, so the phase reports **non-converged** and offers no
quantitative importance claim.

The pilot cost 3,518 seconds and its artifacts are `outputs/v2/p07/sensitivity-manifest.json` and
`sensitivity-levels.parquet`.

## Estimates as they came out

The level table carries every finite-sample estimate unclipped: **2 negative S1 values**, 0 NaN and 0
values above one, each with its confidence bounds. A negative S1 is a finite-sample artefact, not a
share, and it is retained rather than trimmed; the report does not describe any of these numbers as a
quantitative importance.

Two things the artifact does *not* claim, and says so in the manifest: PAWN and Sobol are two
statistics of the same model behaviour and their agreement would not be evidence of a mechanism; and
no near-constant output was given a reading.

## Independent review

Verdict: **blocked then fixed** — one blocker and four majors. The artifacts were not re-run (a
ladder costs an hour); the code was corrected and the artifact gaps are stated where they are.

- **BLOCKER — the Morris ladder never refused a near-constant output.** Only the Sobol path called
  `_near_constant`, so a constant output would have made every elementary effect zero, left the
  ranking to the tie-break and returned `stable=True` with agreement 1.00 — a settled ranking on an
  output with nothing in it. The reviewer reached it with a stubbed simulator. Fixed: the Morris
  ladder makes the same refusal, with a test that stubs the outputs and asserts the refusal, and the
  ranking is reported empty when it does.
- **MAJOR — the Sobol gate ignored the ranking clause it declares.** The code checked only the
  largest relative S1 move; the declared condition also requires the strongest parameters to be the
  same set. The stored artifact shows the ranking *did* change order between N = 64 and N = 128, so
  the missing clause was load-bearing. Fixed and tested; a NaN S1 no longer corrupts the sort.
- **MAJOR — ST was computed and discarded.** The artifact carries S1 only. The code now keeps ST
  beside S1 at every level; the **stored** table predates that change and is reported as S1-only
  rather than described as carrying both.
- **MAJOR — the manifest omitted the seed, the window, the held parameters and their values.** The
  exec plan said the holds would be named in the manifest and they were not; nor was the
  `interest_rate_monthly` substitution that changed an actual run input. The writer now records the
  seed, the window, the held parameters and their values; the stored manifest predates it, and the
  gap is stated here rather than repaired by hand — a generated artifact is regenerated, not edited.
- **MINOR — a partially-NAO output could reach SALib.** `_near_constant` filters to finite values
  before judging, so a half-NaN series passes the spread test; no artifact has one, and the note is
  carried to the next phase.
- **Independently confirmed**: every report number recomputes from the manifest; the bootstrap really
  resamples whole trajectories; the negative S1 estimates are retained with their bounds and nothing
  is clipped or presented as a share; the un-run CRN and tipping bounds are declared as declarations
  and not presented as results; and the manifest hash recomputes.

## Open items for V2-P08 and later

- **The Morris stability test is brittle as declared**: exact agreement of a four-parameter set out of
  thirteen is a very strict reading of "the bootstrap reproduces the ranking". The next ladder should
  re-declare the criterion *before* it runs — an overlap share, say — and the manifest records both
  readings rather than only the one that looks better.
- **The Sobol stage did not reach N = 256.** The affordable pilot ran two rungs and stopped because
  S1 had not settled, which is a statement about cost, not about the model.
- **The CRN arm ladder and the tipping grid are declared and not yet run**: their bounds are in the
  manifest so the next phase runs them to a declared stop rather than to a size.
- **A card defect was found and worked around, not fixed**: `interest_rate_monthly` states a central
  value below its own range. The Sobol stage holds such a parameter at the nearest endpoint of its
  declared range and the substitution is visible in `centre_draw`; fixing the card is V2-P01's.
