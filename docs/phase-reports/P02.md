# P02 — Historical Space / Time / Climate

Date: 2026-09-12
Status: complete. No P03 work started.

## Scope

Give the kernel a space, a season and an exogenous forcing: county and boundary nodes with
provenance, the three separate movement graphs, a monthly agricultural calendar, and a
climate-shock interface in three modes. No households, no markets, no rebels, no LLM.

### Acceptance criteria

```text
CountyNode schema · Shaanxi/Henan county-node representation · three separate NetworkX
graphs · edges carrying distance/cost/capacity/risk · external boundary nodes · monthly
agricultural calendar · ClimateShock baseline/observed-historical/synthetic · provenance
fields · 5-node toy fixture · regional fixture schema scaling to 50–100 nodes · tests for
graph separation, connectivity, invalid edge cost, climate replay, monthly calendar ·
real-data adapter/schema only, no bulk filling without provenance · ADR on node/catchment
geography
```

### Non-goals (explicitly not built)

No households or cohorts; no market clearing, credit or elites; no rebels or armed bands; no
production function (severity is a forcing, not a yield); no USTC client; no calibration; no
UI; no bundled historical dataset.

## Contract decisions

1. **Nodes and catchments, never polygons.** The ADR records the decision, the rejected
   alternatives (digitized boundaries, raster, one adjacency graph, least-cost surfaces) and
   the accepted costs (no area, no density, no border effects, no intra-county space). The
   catchment is expressed by a node's links and its agrarian zone; no radius or polygon is
   stored, because either would be a fabricated boundary.
2. **Coordinates are factual claims.** A `NodeLocation` graded `S` is refused in code, and the
   toy fixture carries none. A dataset with no sourced points is still a valid dataset.
3. **Distance is pair-level, cost is graph-level.** The same pair of places must state the same
   `distance_km` in every graph it appears in, while `cost`, `capacity` and `risk` differ per
   graph and are documented by an `EdgeSemantics` record. One test mutates a trade edge and
   asserts migration and military graphs cannot see it.
4. **Three genuinely separate graphs.** Counties appear in all three; a boundary node appears
   only where its declared role allows (trade link, migration exit, military link); the toy
   fixture's node sets are 7 / 8 / 6. Each graph must be connected over its own node set.
5. **Boundary nodes carry no agriculture.** An external node has roles and no agrarian zone;
   the climate system skips it. This keeps "outside the modelled region" honest instead of
   extrapolating agriculture the model does not have.
6. **Zones are environments, not jurisdictions.** Cropping pattern and anomaly sensitivity are
   properties of a zone, so re-sourcing them does not disturb administrative geography. The
   default calendar's phase and sensitivity values are all grade `S`, with the Gregorian-month
   approximation stated in each entry's provenance note; the lunar calendar and its
   intercalary months are *not* modelled, and that is recorded as a gap rather than hidden.
7. **Climate is a forcing, not a yield.** A shock is a severity in `[0, 1]` per node and month;
   the calendar supplies a month sensitivity; their product is recorded as `impact`. The
   production function that turns impact into grain belongs to P03.
8. **Three modes with different epistemics.** `baseline` is the zero reference; `synthetic`
   draws from `climate_rng`; `observed-historical` replays a sourced series, refuses a series
   graded `S`, consumes no randomness, and fails closed on the first uncovered node-month. The
   mode appears in the event log as both `outcome` and `rule_version`, so no run's forcing is
   anonymous.
9. **Unconditional draws for common random numbers.** Synthetic forcing always takes exactly
   two draws per node-month, in canonical node-id order, regardless of whether the draw
   produces an event. A counterfactual that changes the event probability therefore keeps the
   same underlying random numbers; the pinned regression digest protects that ordering.
10. **Real data enters through one door.** `networks/adapter.py` reads a normalized node table
    and three edge tables, requires the provenance columns, and rejects a row without a grade.
    No fetching, no bulk filling, no defaulted provenance. The only dataset in the repository
    is the toy fixture, and it is labelled as such in code, in the fixture docstring, in the
    README and in this report.
11. **Regional scale is the same schema.** The 60-county, 64-node dataset built inside
    `tests/unit/test_spatial_dataset.py` validates and builds all three graphs, so the
    representation is not a dev-scale artefact.
12. **Dependencies.** `networkx` is used now, so `types-networkx` was added as a dev
    dependency to keep `mypy` strict rather than silencing the import.

## Open items for P03 and later

- **Zones are incomplete.** The two zones do not cover all of Shaanxi (the Han river valley is
  a different cropping environment) and say nothing about Henan's south. Adding zones is
  cheap; sourcing their calendars is not, and is P08 work.
- **No node coordinates yet.** Nothing in the model needs them, and nothing fabricates them;
  the first sourced point dataset will exercise `networks.adapter` and `NodeLocation`.
- **Link symmetry is an assumption.** Each edge has one cost for both directions. Terrain and
  river-crossing asymmetry is real, and a directional variant would mean extending
  `EdgeMetrics` — deferred until a mechanism needs it.
- **Topology is declared, not derived.** Which links exist is itself a graded modelling choice;
  the toy fixture's topology must not survive into a historical dataset.
- **The macro frame has no spatial columns.** Climate impacts are in the event log per node;
  whether the macro frame gains per-zone or per-province aggregates should be decided when the
  first consumer exists (P03 bookkeeping or P09 pattern-oriented calibration).
- **Calendar sensitivity is grade `S` and therefore a Morris screening target** once P10
  exists; conclusions must not rest on these month weights before then.
