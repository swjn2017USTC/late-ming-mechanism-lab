# V2-P04 — Failed Hold-out Mechanisms

Status: complete. Run against `docs/exec-plans/V2-P04.md`. No V2-P05 work started.

## What was done

V1's reserved windows failed in four places. The phase attributes each failure, records the chains
behind them, and runs competing structures on the same historical input and the same world seeds.

### 1. The four failures, attributed

`docs/v2/hold-out-diagnosis.{md,json}`, generated by `late-ming-lab experiment p04`. Each entry
records the surface the check was read on, V1's recorded share, the reference run's numbers on the
historical core, and the boundary that stays open.

| pattern | check | read on | class | the evidence |
| --- | --- | --- | --- | --- |
| `chongzhen-drought-sequence` | `shock-peak-in-late-years` | hold-out / whole-run | **data** | with the observed forcing the worst year *is* late: peak severity 1640 in the hold-out window and 1643 in the extrapolation window, against 1625/1635 for the synthetic draws V1 scored |
| `famine-local-price-extremes` | `dispersion-widens` | calibration mismatch | **structure** | the inventory rule binds 0.857 of node-months and the ceiling **never** binds (`price_bound_share.ceiling` 0.000, max posted 2.19 against a 3.6 ceiling); demand with no silver behind it — 88,925 shi over the run — is invisible to the price |
| `relief-overwhelmed-in-worst-years` | `relief-coverage-falls-as-need-peaks` | hold-out / extrapolation | **structure** | of the four bottlenecks, stock and logistics bind in **no** county-month, silver in 0.195 and **eligibility in 0.805**: what the model reports as coverage is mostly an eligibility composition, and four fifths of cohorts never qualify |
| `shaanxi-net-outflow` | `exits-in-crisis-years` | hold-out / extrapolation | **structure** | the reference run has **0 exits and 6 departures in 240 ticks**; the gate is `not-eligible` in 93.9% of cohort-months and `silver` in 5.9%, so the road is closed by two rules rather than by the weather |

The price failure is a calibration-window mismatch check, not a hold-out one
(`docs/calibration/mismatch.md`), and the prediction path refuses that window: V2-P03's isolation is
not suspended to re-score it, and what the phase adds is the chain behind it.

## Independent review

An adversarial reviewer worked from the tree. Verdict: **approve-with-followups**, no blockers, three
majors, six minors. What it found and what was done:

- **MAJOR — an impostor arm labelled `reference` was exempt from the detector** and would have poisoned
  the baseline every other arm is compared against. Fixed: two arms sharing a label are refused, and
  the reference must declare no effect and an empty diff.
- **MAJOR — an ablation with a non-empty but inert diff was accepted** ("reproduced the reference").
  Fixed: an ablation whose configuration diff is non-empty is refused, because the parameter is then
  not what carries the intervention.
- **MAJOR — a run could not show the parameters that built it**: `config.snapshot.yaml` holds the
  kernel configuration and not the parameter sets. Fixed: every arm writes `holdout-arm.json` beside
  its run, with its declaration, diff and the parameter sets actually used.
- **MAJOR — the relief classification was not supported by the numbers the JSON carried.** The
  reviewer is right: the evidence is model-side, and the entry's own boundary admitted the mechanism
  question was open. The entry is reclassified **structure**, with the eligibility composition named
  as the finding and the ratio's defect named separately.
- **MINORS, all fixed**: a misspelled override name was silently ignored by `model_copy` (now refused
  by name); the moved-facts list was truncated to four per arm (now complete); a card's reasoning
  overstated the posted-price range (corrected to the months with local need); the exec plan's non-goal
  about pins contradicted the phase (amended, with the amendment recorded); the exec plan named one
  card file where the registry needs one per parameter set (corrected).
- **Independently confirmed**: both ablation arms byte-identical to the reference (SHA-256 of both
  parquet files), all 20 run digests recomputable from the stored logs, both variants intervening, the
  behaviour-preservation comparison row by row, and no threshold in the frozen protocol touched.

## Open items for V2-P05 and later

- **The relief eligibility line is the binding constraint in four fifths of county-months**, and
  whether that rule is right is a V2-P05 question. The record does not yet say which bottleneck the
  historical relief system actually hit; the chain events now make the model's own answer readable.
- **The V1 Morris batch predates the four new parameters**, so the synthesis sweeps only what that
  batch varied. Sweeping the new ones needs the V2-P07 sensitivity batch, and until then their cards
  are in the pool but not screened.
- **The price rule's ceiling is a declared ratio**, so the phase can say which constraint bound and by
  how far, never whether the model reaches a recorded famine price (4 tael per dou at Shangzhou in
  1631). Rebuilding that rule on evidence is a later phase's work, and the recorded dependency is
  stated in the diagnosis.
- **The distress route's two shares are assumptions**, not measurements: the split between internal
  and out-of-region movement in this window is not established by any source the project holds, and
  the 27,186 movers they produce are a property of those assumptions.
- **The historical core's climate is one regional index allocated to months by a declared seasonal
  profile.** The late concentration now reproduces, but a per-node reconstruction and the index's own
  uncertainty are not propagated.
