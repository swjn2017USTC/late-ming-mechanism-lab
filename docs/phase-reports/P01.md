# P01 — Simulation Kernel / Reproducibility

Date: 2026-09-12
Status: complete. No P02 work started.

## Scope

Build a history-free deterministic simulation kernel: configuration, time, randomness,
events, provenance and output. Nothing about Shaanxi, Henan, households, markets, armies or
decision policies is modelled here.

### Acceptance criteria

```text
12 required items: SimulationConfig, Clock, RNG streams, immutable Event, event logger,
RunManifest, Parquet output, DuckDB helper, replayable events, smoke-run CLI,
fixed regression seed, the five required test groups
same config + seed → byte-level or semantic-level reproducible
pytest / ruff / mypy pass; repo clean
```

### Non-goals (explicitly not built)

No historical counties or geography; no agents; no markets or credit; no climate; no USTC
client (runtime LLM remains disabled); no calibration; no UI; no framework added beyond what
P01 uses.

## Contract decisions

1. **Reproducibility definition.** Parquet and YAML artifacts are byte-identical for the same
   code, config and seed; the `simulation_digest` (SHA-256 over the canonical JSON of every
   produced row) is semantic-level and version-independent. `RunManifest.created_at` and
   `RunSummary.duration_seconds` are wall-clock diagnostics, excluded from
   `RunManifest.deterministic_digest()` and from every reproducibility claim.
2. **Run identity.** `run_id = <scenario>-<root_seed>-<config_hash[:12]>`. Repeating a run
   reuses the directory and rewrites identical artifacts; a directory whose manifest has a
   different deterministic digest (different code revision, config or seed) is refused with
   `RunConflictError`, and `--label` exists for a deliberate second run. Provenance is never
   silently mixed.
3. **Immutability of events.** Frozen Pydantic model; `trigger` is stored as a
   `MappingProxyType` (mutation raises `TypeError`) with an explicit field serializer, so the
   model still dumps to plain JSON for Parquet and for the digest. Events are ordered by
   `(tick, seq)`; the logger rejects out-of-window and backwards ticks.
4. **Replayability.** Each event carries tick, phase, agent, region, rule version, RNG stream
   name, the uniform draw in `[0, 1)`, trigger values and outcome, and round-trips losslessly
   through Parquet (`tests/unit/test_events.py`, `tests/integration/...`).
5. **Tick order.** The 17 phases and `tick-order-v1` live in one place; the kernel refuses
   systems registered out of phase order and duplicate system names. P01 ships no system
   implementation — the protocol is the extension point for P02+.
6. **Consequence: P01 draws nothing.** With no domain mechanism registered there is no
   physical quantity to randomise, so the seed changes run identity but not event content.
   This is stated in the docstrings, in `docs/architecture/system-overview.md`, and in
   `tests/integration/...::test_the_seed_changes_run_identity_even_without_mechanisms`.
   Seeded determinism of drawn values is proven where it is real:
   `tests/unit/test_kernel.py::test_same_seed_replays_systems_exactly` registers a test-only
   system that draws from `household_rng` and emits the draw.
7. **State snapshots.** The macro index frame (`macro_timeseries.parquet`, one row per tick
   with the clock columns) is P01's snapshot carrier. No generic "record anything" collector
   was added: the phases that own domain state must define its columns, units and invariants
   rather than emit ad-hoc fields.
8. **Event log content.** One `TICK` marker per tick (phase `bookkeeping`, outcome
   `warmup`/`shock`). It is the clock frame of the event log, not a physical state; every
   macro row is derivable from it.
9. **Manifest completeness.** `parameter_hash` is present but `null` until the evidence
   registry exists (P08). `parameters.snapshot.parquet`, `county_timeseries.parquet` and
   `decision_trace.jsonl` are not written, because no phase produces that data yet.
10. **Runtime LLM.** Off by default; when enabled the config accepts only
    `ustc-deepseek-v4.1` and requires a prompt version, and the manifest records the switch.
    No client, no credential access, no live call, no fixture (RULES 7–13).
11. **Dependencies.** Nothing new at runtime; `types-PyYAML` was added as a dev dependency so
    `mypy` stays strict rather than silencing the `yaml` import.

  climate-shock interface and the agricultural calendar.
- The macro frame needs a designed extension path (climate columns) — either a kernel-level
  contract or explicit per-phase frames; decide when the first macro variables exist.
- Whether systems are registered by the caller (current behaviour) or declared in
  configuration becomes a real question once more than one system exists.
- Repository-level pytest configuration still lacks a `tests/regression`/`tests/integration`
  split convention; it is currently by directory only.
