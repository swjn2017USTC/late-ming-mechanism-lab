**状态** `WEAK` (V1) -> `WEAK` (V2). V1 与 V2 均为 WEAK：V2 补上了「积累/没收」这一支且确实触发，但卡片自己的证伪测试（基期收缩更大）尚未测量，状态不动。

## 史料部分

**支持** `debt-transfers-land`(A 级)记录违约时土地转给贷方;V1 卡片的中介一侧即以此为据。

**挑战** 史料所显示的究竟是分化(两支,轨迹不同),还是一个连续谱,任何来源都未说明。

**反例** V1 自身的运行显示两侧同时发生,这正是该卡为 WEAK 的原因;V2 尚未产生两者分离的运行。

**可否证预测** 累积支应使可评估税基的收缩大于关闭信贷的臂;若不然,分化就没有第二支,卡片应用一句话如此说明。

**不确定性** 两个新参数(没收项与份额)是 S 级假设;该支在历史核心的一个重复中触发 51 次没收,足以说明它活着,不足以度量其效应。
