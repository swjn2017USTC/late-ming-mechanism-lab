# V2-P02 — Historical Core Dataset (scope)

Date: 2026-09-14. Depends on V2-P00 (the freeze), V2-P01 (the rights spine and the snapshots) and on
P02/P07 (the node-and-catchment schema and the three-graph sandbox).

## What this phase does

Build `historical-core-v1`: a sourced historical core for the 1625–1644 Shaanxi–Henan window, on the
CHGIS V6 administrative geography and the REACHES documentary climate record, wired into the sandbox
through the existing adapter. It is a reconstruction with declared rules, not the medium fixture
renamed.

```text
nodes        8-20 county seats valid across the window, chosen by a declared rule (record coverage
             first, then short-step growth, with a per-province quota) and required to lie on the
             documented courier network; every exclusion counted
geography    CHGIS seat identity, coordinates and date range, with our zone rule and uncertainty
             radius declared; boundary exits as sourced gateway seats
graphs       candidate links by proximity, accepted links by graph-specific rules: the documented
             courier chain for military, its major-route subset for trade, range for migration;
             the fewest labelled connectors close each graph, and the documented share is reported
climate      the observed annual index per node-year from REACHES event counts, allocated across
             months by a parameter-carded, ablatable profile; the model never sees a monthly
             "observation"
coverage     node-year, edge-type and field-level coverage reports, with every uncovered
             node-period named and every field's grade, source and locator listed
mode         a new dataset id, schema version and scenario; toy and medium stay for tests
runs         24-tick smoke and the declared 240-tick run, with a V2 provenance sidecar, replay, and
             the event log carrying the forcing's rule version
```

## Non-goals

No V2-P03 work: no outcome definitions, no threshold ensemble, no validation protocol. No parameter
value of an existing set changes, no mechanism is edited, no V1 artifact is rewritten, and no raw
file is committed. The phase does not claim the selected seats were the important places of the
window, and it does not fit anything to a historical outcome.

## Acceptance criteria

```text
every factual field of the core carries a source, a locator and a grade; unknowns are declared
  parameter bands or explicit missing values
the observed mode runs end to end when coverage is declared, and refuses with the exact
  node-periods named when the strict policy is asked for
the three graphs are separate, each honours its roles, and every link is documented or labelled
if fewer than eight reliable seats exist, a gap packet is delivered instead of a filled value
raw rights are respected: no raw file tracked, no record transcribed, derived tables cited
tests/invariants, tests/regression, ruff, ruff format --check and mypy pass
```
