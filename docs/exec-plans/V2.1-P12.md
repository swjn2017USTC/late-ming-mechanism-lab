# V2.1-P12 — Closure Synthesis & Handoff (exec plan)

Run against `docs/OMP_UPGRADE_PLAN_V2_1.md` §V2.1-P12. This is V2.1's last phase. No V3 work
starts, and nothing here turns an unmet gate green.

## What this phase is for

Seal the project honestly and hand it on. V2 produced six mechanism cards, a nine-gate verdict and a
release bundle that is not tagged; V2.1-P10 established what P05's four seeds really are and froze the
three pilots; V2.1-P11 ran the two contrasts the cards left open and moved no status. This phase
recomputes the six cards from the artifacts *with* those results, publishes what is sealed and what is
not, and binds it all so a reader can check the claims rather than trust them.

## The cards

Six cards, recomputed — not copied — from typed accessors over:

| input | what a card reads from it |
| --- | --- |
| `docs/mechanisms/v2/cards.yaml` | the V2 card itself: its status, its record, its lineage — the baseline this phase extends rather than restates |
| `docs/v2/threshold-robustness.json`, `docs/v2/hold-out-diagnosis.json`, `docs/v2/mechanism-variants.json` | the V2 evidence refs, recomputed through the V2 accessors |
| `docs/v2_1/replicate-audit.json` | the replicate semantics of every P05 arm: executions, distinct digests, independent replicates |
| `docs/v2_1/decisive-contrasts.json` | the two contrasts, their paired differences, the falsifier outcomes and the status recommendations |
| `outputs/v2/p06/posterior.json`, `outputs/v2/p07/sensitivity-manifest.json`, `outputs/v2/p08/runtime-arms.json` | the frozen pilots a card's uncertainty names |

Every card carries, in the V2.1 form:

- `v1_status → v2_status → v21_status`, and the reason the second arrow is what it is;
- **replicate semantics and the true independent sample count** — computed from the audit, never from
  prose, with the basis named (which arms, how many executions, how many distinct digests);
- `dataset`, `forcing`, `policy`, `window` and `threshold band`;
- model evidence as `EvidenceRef`s with artifact digests, historical support and challenge,
  counterexample, falsifier, uncertainty;
- the full lineage `source → normalized row → parameter/rule → run → statistic → card`, with every
  locator resolving.

P05's four seeds are **not** written as four independent replicates anywhere in these documents: the
audit's `1 independent replicate, not 4` is what a card prints, and a test fails if a document renders
a one-digest multi-seed execution as independent process replicates.

No status moves. P11 recommends `CONDITIONAL` for M002 (kept) and `WEAK` for M004 (kept); the other
four cards are untouched by V2.1. A phase that found no status change says so; it does not manufacture
one.

## Non-goals

- No gate, threshold, protocol, outcome, window, scenario, parameter card or V2 artifact is edited; a
  gate that did not pass in V2 does not pass here.
- No `v0.2.0-rc1` tag, and no tag of any kind created by this phase.
- No simulation, no new model batch, no network, no runtime LLM, no full `pytest`.
- No new dependency, and no second card format: the V2.1 cards are built *from* `V2Card` and reuse
  `EvidenceRef`, `LineageStep`, `Accessor` and the gate evaluator.
- No claim of causal historical truth from simulation, and no wording that presents a frozen pilot as
  converged.

## Outputs and reproducibility

The pass is `python -m late_ming_lab.release v2_1`. It recomputes the cards, writes every document
and the bundle, and **two consecutive passes must be byte-identical** — asserted in a scratch copy of
the declared inputs so the test never writes into the repository.

The bundle records `git_sha` and `tree_dirty` like V2's, with the bundle's own path excluded from the
dirty check. Its `git_sha` names the commit that carries the generating code: the phase therefore
regenerates the bundle once after its own commit, as V2 did, and the phase report says so.

## Failure conditions

- **A number that does not recompute** — a card quoting a statistic no artifact holds is an error, not
  a stale value.
- **A locator that resolves to nothing** — a card citing a renamed file is refused, as in V2.
- **A translation gap** — a Chinese card missing a field, or reading a V2 translation for text that
  changed, is refused rather than falling back to English.
- **A bundle that is not deterministic** — two passes differing in any byte stop the phase.
- **An unmet gate presented as met** — the limitations document prints the nine verdicts the artifacts
  decide; a gate is never closed by wording.
