# P10 — Ablation / Sensitivity / Counterfactual (scope)

Date: 2026-09-14. Depends on P07 (integrated sandbox), P08 (card ranges) and P09 (the summary
statistics, the windows and the common-random-number pattern).

## What this phase does

Stop asking whether the model looks like history and start asking what each mechanism is *for*.

1. **An experiment runner.** Arms and parameter designs, each run on the P07 sandbox with the same
   outcome extraction, under common random numbers: replicate *r* of every arm uses root seed
   `base_seed + r`, and a design row keeps replicate 0 so variation across the design is the
   parameters and nothing else. Every batch writes its runs, its trajectories and a manifest that
   names the arms, their computed differences from the baseline, the design sizes and the code
   revision.
2. **Ablation.** One declared baseline and the nine mechanisms the plan names, each an ablation of
   it: `NO_DROUGHT`, `NO_EXTRACTION_ESCALATION`, `FULL_MILITARY_PAY`, `HIGH_RELIEF`,
   `NO_ELITE_CREDIT`, `NO_TRADE_DISRUPTION`, `NO_BAND_MERGER`, `LOW_REPRESSION`,
   `OPEN_MIGRATION_EXIT` — plus three two-way arms so an interaction can be measured rather than
   assumed. Two of the nine are only defined against a baseline that switches the mechanism on:
   the sandbox's own default has neither escalating extraction nor disrupted trade, so the declared
   baseline turns both on and says so.
3. **Sensitivity.** Morris over every parameter whose P08 card declares a range and whose field is a
   scalar, to rank influence; then Sobol over the ranked set with second-order indices, so
   interactions are estimated and their confidence intervals reported.
4. **Counterfactual.** Paired comparisons of every arm against the baseline on the required outputs
   — collapse probability, tax-base trajectory, migration distribution, market connectivity,
   military arrears, largest band share, time-to-governance-breakdown — with quantiles, a bootstrap
   interval on the paired median difference, the share of replicates that move the same way and
   Cliff's delta. No comparison is a difference of means.
5. **Reports.** `docs/experiments/{ablation,interactions,sensitivity,tipping}.md`, generated from
   the batch directories: interaction effects against the additivity null, the two-parameter region
   rather than two curves, and the response curves' curvature where a mechanism bends.

## Non-goals

- No mechanism, rule or parameter value changed; no new mechanism added. An arm is a declared
  difference from one baseline, and every value it sets is either the model's own default or a
  declared scenario value with the reason beside it.
- No historical fitting: P09 calibrated against the evidence; this phase measures the model's own
  mechanisms and must not tune anything to a historical pattern.
- No runtime LLM (`USTC_LLM_ENABLED=0`), no regional-scale compute, no UI, no P11 work.
- No claim that an interaction is absent: an interval covering zero is reported as *additive*, which
  means "not visible at this sample size".

## Acceptance criteria

```text
runner with arms and designs · the nine named ablations, each a computed difference from one
declared baseline · Morris → Sobol with second-order indices · common random numbers asserted ·
collapse probability with an interval · the seven required outputs, as distributions · interaction
effects with intervals · tipping region · non-linearity (response curvature) · a report that
regenerates every number from the batch artifacts · provenance per batch · no USTC call
```
