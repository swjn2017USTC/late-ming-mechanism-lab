# V2-P00 — Baseline Freeze & Scientific Audit (scope)

Date: 2026-09-14. Depends on nothing: it is the first V2 phase, and its input is the V1 release
candidate `v0.1.0-rc1` (commit `a81c223216f989150d69fe42bfe0a78f7eab1374`).

## What this phase does

Make the V1 release candidate a *read-only scientific baseline*, and say honestly what it is worth.
Nothing about the model changes: no mechanism, no parameter value, no tick-order entry, no historical
data, no artifact content.

```text
freeze     docs/v2/baseline-v1.json: SHA-256 of code, config, data cards, artifacts and reports,
           with each artifact's own generation commit read from the artifact, never HEAD
verify     late-ming-lab baseline verify: fails closed on any modified or missing frozen file
audit      docs/v2/v1-acceptance-matrix.md: the plan's Milestone M1, Milestone M2 and twelve final
           success criteria, each marked met/partial/unmet/not-testable with its evidence
cards      every V1 mechanism card with its dataset, climate mode, sample size, policy arms and
           extrapolation limits, read from the artifacts rather than transcribed
readiness  docs/v2/scientific-readiness.md: the boundary between engineering RC, synthetic-mechanism
           experiment and regional historical model
conventions  where V2 phase reports and exec plans live, so P01-P09 do not invent their own
```

## Non-goals

- No V2-P01 work: no source acquisition, no rights review, no data conversion, no new dataset.
- No mechanism, parameter, rule, tick-order or historical-data change; no re-run of any batch; no
  new artifact written under `outputs/`.
- No re-tagging: `v0.1.0-rc1` stays exactly where it is, and no V1 document is corrected in place —
  where the audit finds V1 prose the artifacts do not support, the audit records it.
- No UI, no new dependency, no runtime LLM call, no cluster work.

## Acceptance criteria

```text
v0.1.0-rc1 unmoved, its content unchanged, and the working tree clean at the end
a machine-readable baseline manifest that rebuilds byte-identically and detects any file drift
each artifact recorded with the commit it was generated at, not with the current HEAD
M1, M2 and the twelve success criteria marked and evidenced with paths that resolve
every V1 mechanism card listed with dataset, climate mode, sample size, policy arms, extrapolation
full pytest, ruff, ruff format --check, mypy and doctor run and reported with their real output
an independent read-only review of sample sizes, synthetic inputs, thresholds, runtime refusal and
artifact lineage
```

## Stop

V2-P00 report, review, logical commit, clean tree, stop. V2-P01 is not started.
