# P09 — Calibration / Hold-out (scope)

Date: 2026-09-13. Depends on P08 (evidence registry, frozen by digest) and P07 (integrated sandbox).

## What this phase does

Turn the P08 pattern registry into an explicit, window-disciplined calibration pipeline, run it at
small scale, and report what it can and cannot identify.

Windows are fixed before any fitting and never renegotiated:

```text
calibration    1625-01 to 1634-12   ticks   0-119   the only window any objective may read
hold-out       1635-01 to 1642-12   ticks 120-215   never in an objective; used to predict
extrapolation  1643-01 to 1644-12   ticks 216-239   the hard case, beyond the apparent regime
```

1. **Summary statistics API** — a fixed-order vector of scalars, each declared with unit and the
   event that carries it, computed only from the event log and sliced by window; plus the per-tick
   series a co-movement check needs.
2. **Pattern distance metrics** — every `calibration_role: target` pattern becomes a small set of
   checks read off the window statistics and series, scoring directions, orderings and co-movement.
   No historical magnitude is fitted: P08 records shapes, not series.
3. **Priors** — declared only for parameters that carry a P08 card *with a numeric range*; the
   range is the prior's support, so no bound is invented here.
4. **ABC simulator wrapper** — a parameter draw becomes parameter sets, a fixed historical-shock
   toy scenario, a fixed root seed (common random numbers) and one 240-tick kernel run, summarised
   in the calibration window.
5. **PyMC integration and SMC** — `pm.Simulator` with a Laplace distance on the pattern scores,
   sampled with `pm.sample_smc` at small scale.
6. **Ensembles, not best fits** — the accepted draws, their weights and their per-target distances
   are persisted with full provenance; the posterior predictive runs report the hold-out and
   extrapolation windows the objective never saw.
7. **Reports** — which parameters are identifiable, which are equifinal, which patterns the model
   cannot match, and which calibration attempts failed. Failure is a reportable outcome.

## Non-goals

- No single best-fit parameter set, no point estimate presented as *the* calibration.
- No tuning of a mechanism to make a historical pattern come out; P08's recorded gaps (price
  ceiling, migration gating, mortality absence) stay recorded, not fixed.
- No large compute: the batch is sized to run on this machine in minutes, and the pipeline is
  validated at that scale rather than at the regional one.
- No hold-out or extrapolation observation in any objective, structurally not by convention.
- No new mechanism, no kernel or scheduler change, no runtime LLM (`USTC_LLM_ENABLED=0`).
- No archival acquisition; P08's acquisition queue stays human work.

## Acceptance criteria

```text
windows declared once and enforced · objective proven blind to post-calibration events ·
every target pattern mapped to checks with a declared tolerance · no fitted magnitudes ·
priors bounded by P08 card ranges, refusal otherwise · pm.Simulator + sample_smc path ·
accepted-draw ensemble persisted with provenance and reproducible from its manifest ·
posterior predictive runs scored on hold-out and extrapolation · identifiable vs equifinal
verdict per parameter · patterns the model cannot match named · failures reported ·
P08 registry frozen by digest and checked · no mechanism changed to fit history
```
