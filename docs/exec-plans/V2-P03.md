# V2-P03 — Outcome & Validation Protocol

Exec plan for `docs/phase-reports/V2-P03.md`. Written before the phase's own results were read, so
every definition below is pre-registered rather than chosen after the fact. The convention this file
follows is `docs/v2/phase-conventions.md`; the plan it implements is `docs/OMP_UPGRADE_PLAN_V2.md` §6
(V2-P03), and its prompt is `docs/OMP_UPGRADE_PROMPTS_V2.md` § "Prompt 3".

## Why

V1's verdicts are read off eight declared governance thresholds, seven of them graded `S`. A single
derived number — `breakdown`, the count of crossed lines — carried the headline, so "the county broke
down" was a sentence about eight choices as much as about the model. V2-P03 freezes, before any V2
result exists, what an outcome is, which window it is read in, what a missing value means, and how far
a verdict is allowed to move when a line moves.

## Scope

1. **A frozen protocol**, `data/protocol/validation-protocol-v2.yaml`, with its schema and its
   identity in `src/late_ming_lab/protocol/{schema,freeze}.py`: nine primary outcomes across seven
   dimensions (fiscal realisation and base, arrears, relief coverage, military supply, migration,
   market connectivity, livelihood shortfall, armed concentration), each with a direction, an
   aggregation, the measured quantities it is read from, a minimum substantive effect, and the
   strongest comparison level the historical record can support (`direction`, `ordering`, `magnitude`,
   `none`). `breakdown` and the crossed count stay as **derived readings**, reported, never primary.
2. **Windows and isolation in both directions**, `protocol/freeze.py`: calibration / hold-out /
   extrapolation tile the 240-tick run; fitting may read only the calibration window, scoring only
   hold-out and extrapolation, and a batch carries the protocol digest it was scored under. A batch
   recorded under another protocol — or under none — is refused rather than re-read.
3. **A threshold ensemble**, `data/protocol/threshold-ensemble-v2.yaml` and `protocol/thresholds.py`:
   for each of the eight lines, the live value, the band it could be read over, what the band rests
   on, whether the line is a normative choice or a model assumption, and how the band is sampled. The
   design is enumerated whole — 50,625 members — so no report can be accused of picking a favourable
   member.
4. **A model-comparison register**, `data/protocol/model-comparison-register-v2.yaml` and
   `protocol/comparison.py`: the candidate structures V2-P04 and V2-P05 will test, each with its prior
   expectation, the observables that discriminate them (protocol outcome ids only) and the
   observation that would falsify it.
5. **A robustness report**, `protocol/{outcomes,measures,robustness}.py` and `protocol/report.py`,
   generated into `docs/v2/threshold-robustness.{md,json}` by `late-ming-lab protocol robustness`:
   for each mechanism card, the share of ensemble members under which its reading holds, changes, or
   cannot be decided, at every crossed count the protocol allows the breakdown reading to be taken at.

## Non-goals

- No mechanism change, no parameter tuning, no new actor, no new event type.
- No formal V2 calibration, no hold-out score read as a V2 result, no V2 result at all.
- No editing of any V1 document, artifact or module beyond the one naming change (`runner.
  _parameter_sets` → `runner.arm_parameter_sets`, so the pilot builds the same economy the batch
  does rather than a second copy of that mapping).
- No claim that a threshold is a historical fact, and no replacement of a measured quantity with a
  line.

## The pilot, and what it is not

The robustness report needs runs whose event logs are kept, because a line can only be moved over a
*measurement*. The phase runs a declared pilot — `BASELINE`, `OPEN_MIGRATION_EXIT`, `NO_ELITE_CREDIT`
at four seeds, 240 ticks, into `outputs/pilot/v2-p03/`, and it is not a result: it fits nothing, its
arms are the sandbox's declared scenarios rather than the historical core, and its numbers appear only
as measurements a threshold was applied to. Each run's log, manifest and measures are written, so a
later phase can re-score it without re-running it.

## Acceptance

- Every later V2 report reads its definitions from the frozen protocol; the protocol has a version and
  a content digest, and a batch scored under a different one fails closed.
- No threshold is written as a historical fact; the dependence of each mechanism reading on the
  ensemble is reported as a share, and no single favourable member is selected.
- Window mixing is refused in both directions by code, with tests.
- `pytest`, `ruff check`, `ruff format --check`, `mypy` and `doctor` pass, with their real output in
  the phase report; an independent review looks for a single-threshold flip of a core conclusion.
- `docs/phase-reports/V2-P03.md`, logical commits, clean tree, STOP. V2-P04 is not started.
