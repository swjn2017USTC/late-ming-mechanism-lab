# P12 — Decision-Policy Robustness (scope)

Date: 2026-09-14. Depends on P11 (the runtime layer, its gate and its seats), P10 (the mechanisms'
measurement habits) and P07's sandbox.

## What this phase does

Run the same world under four decision policies and ask what changes when the *rule for deciding*
does. Everything else is held fixed: one configuration, one set of parameter values, one seed per
replicate — replicate *r* of every policy starts from root seed `base_seed + r`, so a difference
between arms at the same replicate is the policy and nothing else.

```text
rule      a declared threshold table
utility   a bounded linear objective over the observed readings
random    a seeded control
ustc      the runtime model, which fails closed unless the model id is operator-confirmed
```

Five questions, each answered from the artifacts rather than from a story:

1. does **Fiscal Extraction Inversion** — the county working harder while realising less — survive a
   change of policy?
2. does the **Fiscal-Military Ratchet** — pay arrears accumulating and never clearing — survive one?
3. does the **crisis tipping region** move, over fiscal pressure against climate severity?
4. does **armed-band consolidation** depend on the model, or on the policy at all?
5. do policy differences change **levels**, or the **mechanisms** themselves?

The product is a **policy-robustness matrix** and a declared verdict per mechanism: *robust* when
three or more arms show it, *mixed* at two, *model-dependent* when the runtime arm is the only one,
*policy-dependent* when a single declared policy is, and *absent* when none is — with an arm that did
not run contributing nothing rather than being guessed.

## Non-goals

- No "the LLM looks historical, therefore the LLM is right". A mechanism only a model-backed arm
  shows is marked *model-dependent* and nothing is concluded from it about history or about the
  model's truth.
- No large LLM experiment: the decision layer is a handful of seats, event-triggered, and the phase
  reports how many decisions it actually made.
- No change to any mechanism, rule or parameter value; P12 measures, it does not tune.
- No claim from an arm that did not run: the runtime arm's absence is reported, not imputed.

## Acceptance criteria

```text
four arms compared under common random numbers · the five questions answered from artifacts ·
a policy-robustness matrix · declared verdict rules applied before the runs · mechanism readings
falsifiable and tested at their boundaries · artifacts a report can be regenerated from ·
runtime arm refused and recorded, not imputed · no mechanism changed to make an arm agree
```
