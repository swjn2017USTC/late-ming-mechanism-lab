# V2-P01 — Evidence & Rights Spine (scope)

Date: 2026-09-14. Depends on V2-P00 (the frozen baseline and the acceptance audit) and on P08 (the
source registry, the evidence ledger, the parameter cards and the pattern registry).

## What this phase does

Give V2 an evidence base whose inputs are legal, located, checkable and honest about how far they
were read. It is an evidence phase: no parameter value changes, no mechanism changes, no calibration
runs, and no V1 artifact is rewritten.

```text
snapshots   a manifest schema for files: source, version, locator, rights, acquisition method,
            download timestamp, SHA-256, redistribution status, derived-output rule
opening     the public sources V2 will actually use — CHGIS V6, the REACHES database, Chen et al.
            2024 — and the thirteen registry records P08 left unverified, each opened or explicitly
            left unverified with a next action
rights      who may do what: CHGIS academic-only and no redistribution, REACHES unresolved, Chen et
            al. CC BY, and the rule that follows for each
ranking     the eight evidence domains ordered by decision relevance x evidence debt, with every
            component printed
reports     coverage, uncertainty and gaps now carry rights, verification and read depth; a new
            ranked task list is generated beside them
```

## Non-goals

- No parameter value, prior, range or grade is inferred from a source this phase opened. Opening a
  page verifies an identity; it does not license a number.
- No tuning, no calibration, no model run, no mechanism edit, no tick-order change.
- No agent acquisition of institution-gated material: the queue stays human, and the record says
  what the person is being asked for.
- No raw file enters git. Every snapshot lands under `data/raw/private/`, which is ignored, and the
  repository keeps the record, the rule and the hash.
- No V1 artifact is touched; `outputs/` is unchanged.

## Acceptance criteria

```text
every source V2 cites is either opened and checked, or unverified with a next action recorded
a manifest record per acquired file, with version, locator, rights, method, timestamp and SHA-256
restricted and unclear-rights material absent from git, with the acquisition script and rule instead
the source -> claim -> parameter/rule chain still complete in both directions
coverage, uncertainty and gaps report rights, verification and read depth
the eight evidence domains ranked by relevance x debt, with the components shown
an independent review that checks locators, grade caps, rights judgments and claim aptness
full pytest, ruff, ruff format --check and mypy clean; doctor green
```
