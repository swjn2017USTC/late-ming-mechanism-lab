# V2.1-P10 — Replicate Semantics & Pilot Freeze (exec plan)

Run against `docs/OMP_UPGRADE_PLAN_V2_1.md` §5. No V2.1-P11 work starts in this phase.

## The question this phase answers

P05's 40 historical-core runs are 10 arms × 4 `root_seed` values, and every arm's four runs carry
**one** simulation digest with **zero** non-null `rng_draw` rows in the log. Two readings are
possible and they are not equivalent:

1. the observed-forcing path is draw-free **by design**, so the four seeds are four executions of
   one deterministic trajectory; or
2. a subsystem the design declares as random does not consume its stream, so the four seeds are
   four independent replicates whose randomness is missing.

The phase decides which, states it without hedging, and freezes what V2 actually established.

## Non-goals (explicit)

- No simulation. No 240-tick run, no toy run, no ladder rung, no `experiment` family invocation.
- No rewrite of `outputs/v2/**`, `docs/v2/**`, any V1 artifact, any V1 phase report, any V1 test.
- No change to model mechanisms, tick order, RNG architecture, thresholds, protocol, gates or
  scenario declarations. A defect found here is reported, not repaired.
- No parameter-card edit: `data/parameters/*.yaml` feeds `evidence_digest`, which the frozen
  `outputs/v2/p06/posterior.json` records, so editing a card would break an artifact this phase
  may not rewrite. No `central` value is moved for any reason.
- No new dependency, no runtime LLM call, no network, no `live_ustc`, no full `pytest`.
- No promotion of any V2 result: nothing here turns a `non-converged` ladder into a converged one,
  or the P08 pilot into an upgraded M2.

## Acceptance criteria

1. Each of the 10 P05 arms reports: declared seeds, run count, distinct simulation digests,
   non-null `rng_draw` rows, and the number of distinct values of each declared key reading.
2. The determinism question is answered as **deterministic replay by design** or as an **RNG
   wiring blocker**, with the evidence that decides it, in a declared procedure: which call in the
   tick path can draw, which climate model the historical core selects, and whether any design
   document declares a subsystem that must draw and does not.
3. The pilot disposition carries: P05's four seeds = one trajectory executed four times; P06 frozen
   `non-converged`; P07's final-code/stale-artifact field differences, enumerated; P08 pilot with
   zero model decisions.
4. The parameter-registry findings are recomputed, not copied: the `interest_rate_monthly`
   central/range conflict, and the range-carrying cards in neither the calibration declaration nor
   the excluded list. Each finding is resolved by explicit exclusion, range removal, or a
   registered carried item — with the reason the other routes were not taken, and no edited
   `central`.
5. A regression test fails if a multi-seed execution whose distinct digest count is 1 is rendered
   as independent process replicates.
6. `python -m late_ming_lab.release verify` still reports 0 drift, and P05–P08 artifacts are
   byte-identical to what they were before the phase.

## Failure conditions

- **Blocker — an undeclared random path.** If the tick path contains a draw the historical core
  cannot avoid, or a document declares a subsystem that must consume a stream and the historical
  core consumes none, the phase stops at the finding: report, commit, `STOP`, and V2.1-P11 does not
  start. Fixing the mechanism is out of scope.
- **Missing artifact.** A run directory, manifest, summary or event log the audit declares is
  absent: report it as absent. Absence is not zero, and a missing run is not a failed one.
- **Report/artifact disagreement.** Where a V2 phase report states something a typed artifact
  contradicts, the artifact decides and the disagreement is recorded as a finding. Neither is
  edited.
- **Budget.** The audit is a read of ~40 Parquet logs plus the documents: minutes, not an hour. Any
  command that would run a simulation, or exceed 10 minutes of machine wall clock, is not run.
